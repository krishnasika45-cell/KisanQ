FINAL UI CLEANUP + POLISH FOR KISANQ

Please improve the existing KisanQ prototype without redesigning the entire website or changing the existing features, navigation, flows, or functionality.

KisanQ is a farmer-focused procurement platform for SIH 2026 (Problem Statement SIH26032).
Tagline: “Smart Procurement. Better Predictability.”

1. GLOBAL LANGUAGE SWITCH
- Do NOT place separate language buttons on every page.
- Create ONE consistent global language selector in the main header.
- It should be available throughout the entire website from the same position.
- Use a compact dropdown:
  English
  हिन्दी
- Changing the language should apply consistently across the current page and all connected screens.
- Keep the language selector visually subtle and professional.
- Do not duplicate language controls inside individual page content unless absolutely necessary.

2. FIX OVERLAPPING UI
- Carefully inspect every screen for overlapping cards, text, buttons, icons, navigation, headers, and bottom navigation.
- Fix all spacing, padding, margins, alignment, and responsive issues.
- Nothing should overlap or be clipped.
- Make sure cards have enough height for their content.
- Make buttons and text remain inside their containers at all screen sizes.
- Check both desktop and mobile layouts.

3. CLEANER TYPOGRAPHY
- Reduce unnecessary text wherever possible.
- Keep headings short and clear.
- Avoid paragraphs inside small cards.
- Improve font hierarchy:
  Page title → Section title → Card title → Supporting text.
- Use consistent font sizes, weights, and line heights throughout the application.
- Keep farmer-friendly language simple and readable.
- Do not overcrowd screens with information.

4. UI CONSISTENCY
Create one consistent KisanQ design system across ALL screens:
- Same green brand color
- Same button styles
- Same card radius
- Same shadows
- Same icon style
- Same spacing system
- Same typography
- Same header
- Same navigation behavior
- Same status badge style

Do not redesign each page independently.

5. HEADER
Keep a clean global header containing:
- KisanQ logo
- Language selector
- Notification icon
- User/profile menu

Keep the header compact and consistent on every authenticated screen.

7. NAVIGATION
Keep navigation simple and consistent.
Farmer navigation should include:
- Home
- My Booking
- Queue
- Procurement
- Payments
- Profile

Avoid duplicate navigation systems unless required for responsive design.
On desktop use the existing desktop navigation/sidebar structure.
On mobile use bottom navigation where appropriate.

8. RESPONSIVE DESIGN
Make every screen properly responsive:
- Desktop
- Laptop
- Tablet
- Mobile

Cards should stack naturally on smaller screens.
No horizontal overflow.
No text clipping.
No overlapping buttons.
No broken layouts.

9. ACCESSIBILITY
Keep:
- Good text contrast
- Large enough clickable buttons
- Clear focus/active states
- Readable font sizes
- Large Text accessibility option where already implemented
- Hindi text should remain properly aligned and readable.

10. CONTENT CLEANUP
Remove repeated, placeholder, unnecessary, or confusing text.
Do not invent new government features or claim real-time government integration.
Keep the prototype language realistic:
- “Prototype”
- “Estimated wait”
- “Based on current workload”
where appropriate.

Do not claim guaranteed zero waiting.

11. STATUS & DATA UI
Use consistent badges for:
- Confirmed

- Cancelled

Use clear visual hierarchy without making the dashboard visually noisy.

Perform a complete UI quality pass across ALL existing screens.

Fix:
- spacing inconsistencies
- alignment problems
- overlapping elements
- inconsistent card sizes
- inconsistent button styles
- inconsistent icons
- excessive text
- unnecessary empty space

Keep the existing KisanQ prototype and make it look like a polished, production-quality, professional government/farmer-facing application suitable for an SIH 2026 demonstration.
